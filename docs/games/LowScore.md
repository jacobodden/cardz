# Game
Low Score

## Description
A generic scorekeeper for any game where the lowest total wins. It is not a
card game itself — it tracks points across an open-ended number of rounds.

## Setup
- Players: 2 to 10.
- No game-specific configuration is required.

## Gameplay
Each round, enter the points each player earned. Negative points are allowed,
so penalties and bonuses can both be recorded. Press **Submit round** to save
the round and move to the next one.

## Scoring
A player's total is the sum of all their round scores. The lowest total wins.

## Ending the game
There is no fixed round count. Press **Finish game** whenever you are done.
The trailing unscored round is discarded, and the final standings are shown.
**Undo** reopens the game if you finish too early.
