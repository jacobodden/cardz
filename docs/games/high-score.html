High Score

A generic scorekeeper for any game where the highest total wins.

Description

High Score is not a card game itself. It tracks points across an open-ended number of rounds for any game where the highest total wins.

Setup

  • Players: 2 to 10.
  • No game-specific configuration is required.
  • Optionally pick the First dealer (the first player by default).

Gameplay

Each round, enter the points each player earned. Negative points are allowed, so penalties and bonuses can both be recorded. Press Submit round to save the round and move to the next one.

The dealer's card shows a solid D, and the round line names them. After each round the deal passes to the next player. Tap the faint D on any other player's card to make them the dealer instead, for example when the deal goes out of turn. Undo brings back the undone round's dealer too.

Scoring

A player's total is the sum of all their round scores. The highest total wins.

Ending the game

There is no fixed round count. Press Finish game whenever you are done. The trailing unscored round is discarded, and the final standings are shown. Undo reopens the game if you finish too early.
