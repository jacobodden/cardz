Games

Rules for each game Cardz keeps score for. The scoring code lives in src/games/.

  • Up and Down the RiverTrick-taking. Bid the exact number of tricks you will win. Highest total wins.
  • Pay MeContract Rummy over 11 rounds. Lowest total wins.
  • High ScoreOpen-ended points for any game where the highest total wins.
  • Low ScoreOpen-ended points for any game where the lowest total wins.
