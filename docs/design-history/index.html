About these captures

This gallery is a human-readable record of how the design changes over time. The Playwright snapshots in tests/visual/ are the machine-enforced regression guard.

Capturing a new milestone

npm run design:capture

This writes JPEGs to docs/design-history/<YYYY-MM-DD>/ and regenerates this page. Run it when a visual milestone lands, review the gallery, and commit the new dated folder with the updated page. A folder may carry a suffix (for example 2026-11-01-before-redesign) to keep two milestones from the same day apart; every YYYY-MM-DD* folder is listed. The capture is not part of the normal test run or CI.

Visual regression baselines

npm run test:visual          # compare against the committed baselines
npm run test:visual:update   # accept an intentional change

Baselines live in tests/visual/current-ui.spec.ts-snapshots/. Screenshots depend on font rendering, so both commands run inside the pinned Playwright container (podman or docker), the same image CI uses. Review the new images before committing them.
